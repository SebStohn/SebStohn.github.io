# Contact Service

## Overview

Contact Service is a Spring Boot application that provides a simple contact management system with a web-based interface. Users can add, update, search, delete, and view contacts through a REST API backed by a lightweight frontend.

## Features

- Add new contacts
- Search for contacts by ID
- Update existing contact information
- Delete contacts
- Display all stored contacts
- Input validation with descriptive exception handling
- Simple HTML, CSS, and JavaScript frontend

## Technologies

- Java
- Spring Boot
- Maven
- HTML
- CSS
- JavaScript

## Running the Application

### Prerequisites

- Java JDK
- Eclipse IDE
- Maven

### Steps

1. Open the project in Eclipse.
2. Run **Maven Build** with:

   ```
   clean install
   ```

3. Run the application as:

   ```
   Java Application
   ```

   using:

   ```
   ContactApp
   ```

4. Open your browser and navigate to:

   ```
   http://localhost:8080/
   ```
