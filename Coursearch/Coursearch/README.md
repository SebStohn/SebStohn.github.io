# Coursearch

## Overview

Coursearch is a Python application that loads course information from CSV files into a Binary Search Tree (BST). It supports searching, printing, filtering by subject, and generating statistics about the stored course data.

## Features

- Load course data from CSV
- Binary Search Tree implementation
- Search by course number
- Search courses by subject
- Print all courses in sorted order
- Generate tree statistics
- Improved input validation
- Cleaner console output

## Technologies

- Python

## Running the Application

### Prerequisites

- Python 3.x
- PyCharm (recommended)

### Steps

1. Open the project in PyCharm.
2. Configure the Python interpreter.
3. Install all required dependencies.
4. Run:

```
Coursearch.py
```
